ACADEMIC LECTURE NOTES & THEORY DEEP-DIVE

Computer Science (Java) & Economic Theory Foundations

Object-oriented software architecture, algorithmic complexity analysis, microeconomic optimization, and macroeconomic fiscal/monetary models required for College Board 5/5 mastery and Bocconi / TUM admissions:

Module 1: Java Object-Oriented Architecture (AP CS A) 2025-26 CED Unit 3 • OOP Architecture

The 4 Pillars of OOP in Java:
1. Encapsulation: Instance variables declared private, accessed solely through public accessor (getter) and mutator (setter) methods to protect internal object state.
2. Inheritance: A subclass inherits public and protected members of a superclass via the extends keyword. The subclass constructor must invoke super(...) as its very first statement. (Scope note: implementing inheritance is outside the 2025-26 AP CSA course and exam; it remains useful background for university Java courses.)
3. Polymorphism (also beyond the 2025-26 exam scope): An object reference of a superclass type can point to an instance of any subclass:
SuperClass obj = new SubClass(); $\implies$ Method execution is determined at runtime via dynamic method lookup.
4. Abstraction: Abstract classes and interfaces specifying method signatures without concrete implementation.

Array vs. ArrayList Memory Mechanics: Primitive arrays have a fixed size (arr.length). ArrayList<E> is dynamically resizable and stores only object references (using auto-boxing for primitives: Integer, Double). When removing elements from an ArrayList, always loop from back to front (for (int i = list.size() - 1; i >= 0; i--)) to prevent skipping adjacent elements!
Module 2: Algorithmic Complexity & Recursion (AP CS A) 2025-26 CED Unit 4 • Computational Thinking

Big-O Asymptotic Running Time:
• Sequential (Linear) Search: $O(N)$ best for unsorted arrays.
• Binary Search: $O(\log N)$ requires a pre-sorted array, halving search space at each iteration.
• Selection Sort & Insertion Sort: $O(N^2)$ worst and average case quadratic time.
• Merge Sort: $O(N \log N)$ recursive divide-and-conquer algorithm; consistent performance across all data distributions.

Recursive Tracing & The Call Stack: Every recursive method requires: (1) A Base Case that terminates without further recursive calls, and (2) A Recursive Step that moves closer to the base case. Omitting the base case causes a runtime StackOverflowError.
Module 3: Microeconomic Market Structures & Welfare Economics (AP Micro) Unit 3 & 4 • Micro Analysis

The Universal Profit-Maximizing Condition: Every firm maximizes total economic profit by producing up to the quantity where Marginal Revenue equals Marginal Cost ($MR = MC$):
• Perfect Competition: Price-taker firm where $P = MR = AR = D$. In long-run equilibrium, $P = \min(ATC)$ (Allocative efficiency $P = MC$ and Productive efficiency $P = \min ATC$ are both achieved).
• Monopoly: Downward-sloping demand curve where $MR < P$. Produces where $MR = MC$, but charges price $P$ from the demand curve, creating Deadweight Loss (DWL) and underallocating resources.

Pigouvian Taxes & Negative Externalities: When production imposes external costs on society (e.g., pollution), $MSC > MPC$. The free market overproduces ($Q_{mkt} > Q_{opt}$). A per-unit Pigouvian tax equal to the Marginal External Cost ($t = MEC$) internalizes the externality and eliminates deadweight loss.
Module 4: Macroeconomic AD-AS Equilibrium & Policy Multipliers (AP Macro) Unit 3, 4 & 5 • Macro Dynamics

Aggregate Demand & Fiscal Policy Multipliers:
• Marginal Propensity to Consume (MPC) + Marginal Propensity to Save (MPS) = 1.
• Spending Multiplier: $M_s = \frac{1}{MPS} = \frac{1}{1 - MPC}$. An initial increase in government spending ($\Delta G$) expands total GDP by $\Delta Y = \Delta G \cdot M_s$.
• Tax Multiplier: $M_t = -\frac{MPC}{MPS}$. The tax multiplier is always one unit smaller in absolute magnitude than the spending multiplier.

Monetary Transmission Mechanism: When the Central Bank pursues contractionary monetary policy (raising reserve requirements, hiking the policy interest rate, or selling government securities), the money supply contracts $\implies$ nominal interest rates rise $\implies$ investment and interest-sensitive consumption fall $\implies$ Aggregate Demand shifts left, curbing demand-pull inflation.

1.15 & 2.10 String Methods and String Algorithms Topic 1.15 • 2.10

A String is an immutable object: every method returns a new value and never changes the original. Indices start at 0, and substring(a, b) includes index a but excludes index b, so its length is b − a. indexOf(str) returns the index of the first occurrence, or −1 if str is not found. compareTo returns a negative, zero, or positive int based on character codes, and every uppercase letter comes before every lowercase letter.

Comparing Strings: s1.equals(s2) compares the characters; s1 == s2 only asks whether both variables refer to the same object. A String built at run time (for example "A" + w.substring(1)) is a new object, so == can be false even when the text is identical.
AP TRAP — Discarded return values: w.substring(1); on its own line changes nothing. Only an assignment such as w = w.substring(1); updates the variable.
3.3–3.9 & 1.13 Class Design: Constructors, Encapsulation, References and null Topic 1.13 • 3.4 • 3.6 • 3.8

A well-designed class keeps its instance variables private (encapsulation) and exposes behavior through public constructors, accessors, and mutators. A constructor has the class name and no return type; it initializes every instance variable. If a class defines any constructor, Java does not add a no-argument default constructor, so new Book() fails when only Book(String, int) exists. A void method returns nothing and cannot be used inside an expression such as println(...).

Java always passes by value: for a primitive, the method receives a copy of the number; for an object or array, it receives a copy of the reference. The method can therefore change the object's contents but never the caller's primitive variable. After Counter c2 = c1; both variables are aliases of one object.
AP TRAP — null: storing null and testing x == null are safe; calling a method on null (for example x.length()) throws a NullPointerException. The empty String "" is a real object with length 0.
4.8–4.10 ArrayList: Index Shifts While Adding and Removing Topic 4.8 • 4.9 • 4.10

add(obj) appends; add(i, obj) inserts at index i and shifts later elements right; remove(i) deletes and shifts later elements left; set(i, obj) replaces without shifting. Rewrite the whole list after every call: the second remove works on the already shifted list.

Safe traversal patterns: to remove while looping, traverse from the back (for (int i = list.size() - 1; i >= 0; i--)) or decrement i after each removal. After inserting at index i, increase i once more so the same element is not processed again. The condition i < list.size() is re-evaluated on every iteration.
AP TRAP — Enhanced for loops: adding to or removing from an ArrayList inside a for-each loop throws a ConcurrentModificationException. For arrays of primitives, assigning to the for-each variable changes only a copy.
4.11–4.13 2D Arrays: Dimensions and Traversal Order Topic 4.11 • 4.12 • 4.13

new int[rows][cols] creates an array of rows. grid.length is the number of rows and grid[0].length is the number of columns. Row-major traversal uses the row index in the outer loop; column-major traversal uses the column index in the outer loop. Default element values are 0, 0.0, false, or null.

Dependent bounds: when the inner loop starts at the outer index (for (int c = r; ...)), each row visits a different number of cells: this traces the upper triangle including the main diagonal. Sketch the grid and mark the visited cells before adding anything.
4.16–4.17 Recursion: Tracing the Call Stack Topic 4.16 • 4.17

Every recursive method needs a base case that returns without another call and a recursive step that moves toward it. Trace with one line per call, going down until the base case, then combine return values on the way back up. Statements written after the recursive call run during this unwinding, so output appears in reverse order.

Recursive binary search: each call computes mid = (lo + hi) / 2 and recurses on one half. When the target is absent, the search ends with a call where lo > hi, and that call counts too. Merge sort splits the array in half recursively and merges the sorted halves.
4.14–4.15 Searching and Sorting: Intermediate States Topic 4.14 • 4.15

Linear search checks elements in order and returns the first matching index (or −1); it works on unsorted data. Binary search requires sorted data and halves the range each step. Selection sort finds the minimum of the unsorted part and swaps it into position j, so after k passes the first k elements are final. Insertion sort shifts larger elements right and inserts the current element, so after k passes the first k + 1 elements are sorted among themselves.

AP TRAP: "after two passes" questions are designed so that selection sort, insertion sort, and a fully sorted array give different answers. Trace the exact algorithm in the code, one pass at a time.

Unit 5 (10–13% of the multiple-choice section) applies marginal analysis to the markets for labor, land, and capital. Unit 6 (8–13%) asks when free markets fail to reach the socially efficient quantity and how government policy can correct, or fail to correct, the outcome. Weightings: College Board, AP Microeconomics Course.

5.1–5.3 Factor Demand and the Hiring Rule MRP = MRC Micro Topic 5.1 • 5.2 • 5.3

In factor markets the roles reverse: households supply labor, land, and capital, and firms demand them. Factor demand is derived demand: a firm wants workers only because of the revenue their output brings. The value of one more worker is the marginal revenue product, MRP = MP × MR (= MP × P in a perfectly competitive product market). The cost of one more worker is the marginal resource cost (MRC), which equals the wage in a perfectly competitive labor market.

Hiring rule: hire up to the worker for whom MRP = MRC (in a table, the last worker with MRP ≥ MRC). The labor demand curve is the MRP curve; it shifts with the output price, worker productivity, and the prices of other inputs. A change in the wage itself is a movement along the curve. Least-cost rule: MPL / W = MPK / r; shift spending toward the input with the higher marginal product per dollar.
5.4 Monopsony: One Buyer of Labor Micro Topic 5.4

A monopsonist is the only buyer in a labor market. Because it faces an upward-sloping supply curve and must raise the wage for every worker to hire one more, its MRC lies above the supply curve. It hires where MRC = MRP and pays the wage read from the supply curve at that quantity. Compared with a competitive labor market, both employment and the wage are lower.

AP TRAP: never read the monopsony wage from the MRC or MRP curve. Find the quantity at MRC = MRP, then drop down to the supply curve for the wage.
6.1–6.3 Efficiency, Externalities and Public Goods Micro Topic 6.1 • 6.2 • 6.3

The socially efficient quantity is where MSB = MSC. A negative externality (for example pollution) makes MSC = MPC + MEC exceed MPC, so the market overproduces; a per-unit Pigouvian tax equal to the MEC fixes it. A positive externality (for example vaccination) makes MSB exceed MPB, so the market underproduces; a per-unit subsidy equal to the MEB fixes it. Deadweight loss is the triangle between MSB and MSC over the units that are wrongly produced or not produced.

Classifying goods: private goods are rival and excludable; public goods are nonrival and nonexcludable (free-rider problem); common resources are rival but nonexcludable (overuse, the tragedy of the commons); club goods are nonrival but excludable.
6.4–6.5 Government Intervention and Inequality Micro Topic 6.4 • 6.5

Regulating a natural monopoly: the socially optimal price (P = MC) is allocatively efficient but creates a loss, because MC is below a falling ATC; the fair-return price (P = ATC) gives zero economic profit. A lump-sum tax acts like a fixed cost: price and output stay the same and profit falls. A per-unit tax raises MC, so price rises and output falls.

Inequality: a tax is progressive if the average tax rate rises with income, proportional if it is constant, and regressive if it falls. Inequality is shown by the Lorenz curve and measured by the Gini coefficient (0 = perfect equality); a larger Gini means more inequality.

AP MACRO • UNIT 1 & UNIT 6 • BASIC CONCEPTS & OPEN ECONOMY

AP Macroeconomics — Unit 1: Basic Economic Concepts and Unit 6: Open Economy — International Trade and Finance

Unit 1 (5–10% of the multiple-choice section) builds the tools used in every later unit: opportunity cost, the PPC, comparative advantage, and supply and demand. Unit 6 (10–13%) connects the domestic economy to the rest of the world through the balance of payments and the foreign exchange market. Weightings: College Board, AP Macroeconomics Course.

1.1–1.3 Scarcity, the PPC and Comparative Advantage Macro Topic 1.1 • 1.2 • 1.3

The production possibilities curve (PPC) shows the maximum combinations of two goods an economy can produce with its resources and technology. Points on the curve are efficient, points inside show unemployment or inefficiency, and points outside are unattainable. The opportunity cost of one unit of X is the amount of Y given up divided by the X gained. A bowed-out PPC shows increasing opportunity cost. More resources or better technology shift the PPC outward; using idle resources moves the economy toward the curve.

Comparative advantage: a country has an absolute advantage if it produces more with the same resources, and a comparative advantage if it produces at a lower opportunity cost. Both countries gain if each specializes according to comparative advantage and the terms of trade lie between their opportunity costs.
1.4–1.6 Demand, Supply and Market Equilibrium Macro Topic 1.4 • 1.5 • 1.6

A change in a good's own price moves along its demand or supply curve; other determinants shift the curve. Demand shifters include income, the prices of substitutes (price of X up ⇒ demand for its substitute up) and complements (price of X up ⇒ demand for its complement down), tastes, expectations, and the number of buyers.

AP TRAP — Price controls: a price ceiling is binding only if it is below equilibrium, and it causes a shortage equal to Qd − Qs at the ceiling price. A price floor is binding only if it is above equilibrium, and it causes a surplus.
6.1 Balance of Payments Accounts Macro Topic 6.1

The current account records trade in goods and services, net investment income, and net transfers. The financial (capital) account records purchases and sales of assets such as stocks, bonds, real estate, and direct investment. Transactions that bring payments into the country are credits (+); payments going out are debits (−).

The accounts balance: current account + financial account (+ change in official reserves) = 0. A country with a current account deficit must have a financial account surplus, that is, a net inflow of foreign funds.
6.2–6.6 Exchange Rates, the Foreign Exchange Market and Capital Flows Macro Topic 6.2 • 6.3 • 6.4 • 6.5 • 6.6

An exchange rate is the price of one currency in terms of another. If one dollar buys more euros than before, the dollar has appreciated and the euro has depreciated. In the market for dollars, foreigners demand dollars to buy U.S. goods and assets, and Americans supply dollars to buy foreign goods and assets.

Key chains: relative real interest rate up ⇒ financial capital inflow ⇒ demand for the currency up ⇒ appreciation ⇒ exports more expensive, imports cheaper ⇒ net exports down ⇒ AD shifts left. Relative inflation up ⇒ the country's goods become relatively expensive ⇒ demand for its currency down and supply up ⇒ depreciation.
AP TRAP: always ask who is buying and who is selling the currency before you shift a curve, and label the graph "Quantity of dollars" with the price in the other currency.

MODEL 1: AP COMPUTER SCIENCE A FRQ (ARRAYLIST & OOP) Puan Değeri: 9 Puan (College Board Rubriği)

PROBLEM: Depo Envanter Yönetimi (Inventory Management System):
Bir e-ticaret lojistik deposunda her ürünü temsil eden InventoryItem sınıfı bulunmaktadır (getName() ve getQuantity() metotlarına sahiptir).
Warehouse sınıfı içinde tanımlı private ArrayList<InventoryItem> stockList; listesini yöneten şu metodu yazınız:
public void purgeZeroStockAndConsolidate(String targetCategory)
Şartlar: Stoğu 0 olan tüm ürünler listeden güvenli şekilde silinmelidir (ConcurrentModificationException veya atlama hatası olmadan). Belirtilen kategorideki ürünlerin toplam adet sayısı konsola yazdırılmalıdır.

College Board CSA Rubrik Analizi ve Java Çözümü:
public void purgeZeroStockAndConsolidate(String targetCategory) {
    int totalCategoryCount = 0;
    
    // College Board Rubrik Kuralı: ArrayList'ten eleman silerken sondan başa döngü kurulur!
    for (int i = stockList.size() - 1; i >= 0; i--) {
        InventoryItem item = stockList.get(i);
        
        if (item.getQuantity() == 0) {
            stockList.remove(i); // [3 Puan]: Güvenli silme işlemi
        } else {
            // String karşılaştırmasında .equals() kullanımı zorunludur (== 0 puan getirir!)
            if (item.getCategory().equals(targetCategory)) {
                totalCategoryCount += item.getQuantity(); // [3 Puan]: Doğru akümülasyon
            }
        }
    }
    System.out.println("Kategori Toplamı: " + totalCategoryCount); // [1 Puan]
}
• Rubrik Puan Dağılımı: Doğru döngü sınırları (1 pt), elemanların getter ile okunması (2 pt), sondan başa güvenli silme mantığı (3 pt), String eşitlik kontrolü (2 pt), sayaç toplamı (1 pt). Toplam: 9/9 Tam Puan.
MODEL 2: AP MICROECONOMICS & ALMANYA WIRTSCHAFTSGYMNASIUM Piyasa Başarısızlığı & Pigouvian Vergi

FRQ: Kimyasal Üretimde Negatif Üretim Dışsallığı (Negative Production Externality):
Bir kimya fabrikası nehre toksik atık boşaltmaktadır. Özel Marjinal Maliyet MPC = 10 + 2Q, Marjinal Dışsal Zarar MEC = 6 ve Marjinal Özel Fayda MSB = MPB = 70 - Q olarak modellenmiştir.
(a) Serbest piyasa denge üretimini (Q_mkt) ve fiyatını (P_mkt) hesaplayınız.
(b) Toplumsal olarak optimal üretim düzeyini (Q_opt) ve fiyatını (P_opt) bulunuz.
(c) Hükümetin dışsallığı içselleştirmek için koyması gereken Pigouvian birim vergi miktarını ve oluşan ölü dara kaybını (Deadweight Loss) gösteriniz.

Ekonomi Çözüm Adımları & Matematiksel İspat:
• (a) Serbest Piyasa Dengesi: MPB = MPC => 70 - Q = 10 + 2Q => 3Q = 60 => Q_mkt = 20 birim.
Fiyat: P_mkt = 70 - 20 = 50 TL/€.
• (b) Toplumsal Optimal Denge: Marjinal Sosyal Maliyet MSC = MPC + MEC = (10 + 2Q) + 6 = 16 + 2Q.
MSB = MSC => 70 - Q = 16 + 2Q => 3Q = 54 => Q_opt = 18 birim.
Optimal Fiyat: P_opt = 70 - 18 = 52 TL/€.
• (c) Pigouvian Vergi & Ölü Dara Kaybı (DWL):
- Birim Vergi t = MEC = 6 TL/€ (Üretim başına 6 Euro vergi MPC eğrisini tam olarak MSC'ye kaydırır).
- Serbest piyasada aşırı üretim miktarı: ΔQ = Q_mkt - Q_opt = 20 - 18 = 2 birim.
- Ölü Dara Kaybı (Üçgen Alanı): DWL = 0.5 · (MEC) · (ΔQ) = 0.5 · 6 · 2 = 6 Euro.
Bocconi / Münih Değerlendirmesi: Bu analiz hem AP Microeconomics'te 5 getirir, hem de Bocconi İşletme & Finans mülakatlarında çevre ekonomisi sorularının temelidir.
MODEL 3: İTALYA ESAME DI STATO ISTITUTO TECNICO (INFORMATICA) Seconda Prova: Veri Tabanı & İstemci-Sunucu Tasarımı

PROVA SCRITTA (Sistem Mühendisliği ve Veri Tabanı Mimarisi):
Bir akıllı şehir otopark yönetim sistemi için ilişkisel veritabanı şemasını (E-R Diagram) tasarlayınız. Boş park yeri sayısını anlık sorgulayan ve araç plakası bazında ücret tarifesi hesaplayan SQL sorgusunu yazınız.
İtalyan sınav kılavuzuna göre sistemin RESTful API üzerinden mobil cihazlarla JSON formatında haberleşme protokolünü tanımlayınız.

İtalyan Teknik Maturità Çözüm Standardı:
• E-R Şeması: Varlıklar (Sensore, Stallo, Veicolo, Sosta, Tariffa) arasında 1:N ve N:M ilişkiler. Üçüncü Normal Form (3NF) şartı.
• SQL Optimizasyonu: SELECT S.settore, COUNT(*) AS posti_liberi FROM Stallo S WHERE S.stato = 'LIBERO' GROUP BY S.settore; (İndeksleme stratejisiyle B-Tree analizi).
• İtalya Avantajı: Politecnico di Milano Bilgisayar Mühendisliği (Ingegneria Informatica) 1. sınıf "Fondamenti di Informatica" dersiyle birebir örtüşür.
